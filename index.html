02. Mis Repositorios

Aplicación Multiplataforma (AppNova S.L.)

Sistema de Auditoría para Huertos Solares

Desarrollo completo de una aplicación de campo para el mantenimiento de seguidores solares. Arquitectura híbrida que permite a los técnicos trabajar en zonas sin cobertura guardando los datos en local, para después sincronizarlos automáticamente con la nube mediante Supabase al recuperar la conexión. Incluye panel de control web en tiempo real para supervisores, sistema de filtros dinámicos, búsquedas universales y trazabilidad del personal.

  • React Native
  • Supabase (PostgreSQL)
  • SQLite
  • TypeScript
Aplicación Móvil / Salud y Bienestar

HopeUp - Salud Mental

Aplicación orientada al apoyo y seguimiento de la salud mental. Diseñada con interfaces accesibles y amigables para ofrecer un entorno seguro al usuario, facilitando el registro emocional y el acceso a recursos de bienestar desde dispositivos móviles.

  • React Native
  • UX/UI Design
  • Gestión de Estado
Estructuración de Datos

Gestor Botánico en XML

Diseño de arquitectura de datos jerárquica para un registro botánico de especies arbóreas. Implementación de reglas XSLT para transformar los datos brutos en visualizaciones estructuradas.

  • XML
  • XSLT
  • XPath
Software Backend

Sistema de Gestión OOP

Desarrollo de lógica de negocio orientada a objetos. Aplicación de principios SOLID, herencia, encapsulamiento y polimorfismo para garantizar un código escalable y fácil de mantener.

  • Java
  • NetBeans
